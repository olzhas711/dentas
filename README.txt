ДЕНТАС — сайт (прототип), готов к публикации
===========================================

Этот набор файлов можно залить на любой хостинг как есть.
Главная страница — index.html, поэтому сайт сразу откроется по адресу.

Куда заливать:
1) GitHub Pages  — бесплатно, ссылка вида https://имя.github.io/dentas/
                   Инструкция: см. файл «ПУБЛИКАЦИЯ.md» в корне проекта (раздел 1).
2) Netlify Drop  — самый быстрый способ: перетащить эту папку на app.netlify.com/drop
3) Vercel        — vercel.com, «Add New → Project», загрузить папку
4) Свой хостинг  — скопировать файлы в папку сайта (обычно public_html)
                   и подключить домен вида dentas-spb.ru

Что важно:
- Файлы самодостаточны: картинки вшиты внутрь страниц, интернет не нужен.
- Никаких серверных скриптов не требуется — это статический сайт.
- Форма записи в прототипе работает как демонстрация (заявка не уходит).
  Перед реальным запуском нужно подключить отправку заявок: почта, Telegram,
  WhatsApp или CRM клиники — см. раздел «Что нужно от клиники» в дизайн-борде.
